# OS Module in Python

## Introduction

The `os` module is a built-in Python module that allows interaction with the operating system.

It provides functions for working with files, directories, environment variables, and operating system information.

The `os` module makes Python scripts portable across different operating systems.

---

## Common Operations

- Get current working directory
- Create folders
- Rename files
- Delete files
- List directory contents
- Access environment variables

---

## Example

```python
import os

print(os.getcwd())
```

**Output**

```
C:\Users\Harsha
```

(The output depends on your current working directory.)

---

## Advantages

- Built into Python.
- Works on Windows, Linux, and macOS.
- Simplifies system-level operations.

---

## Key Points

- Import using `import os`.
- Used extensively for file and directory management.
- Often combined with automation scripts.
