# Object-Oriented Programming (OOP) in Python

## Introduction

Object-Oriented Programming (OOP) is a programming paradigm that organizes code using **objects** and **classes**. It helps developers write modular, reusable, and maintainable code.

Instead of focusing only on functions, OOP models real-world entities such as students, employees, cars, or bank accounts as objects.

Python fully supports Object-Oriented Programming.

---

## Why Use OOP?

- Improves code reusability.
- Makes applications easier to maintain.
- Organizes large projects efficiently.
- Provides better security using encapsulation.
- Supports code extension through inheritance.

---

## Four Pillars of OOP

- Encapsulation
- Inheritance
- Polymorphism
- Abstraction

---

## Real-Life Example

Consider a **Car**.

A car has:

- Properties → Color, Brand, Model
- Behaviors → Start, Stop, Accelerate

In OOP,

- Properties become **Attributes**
- Behaviors become **Methods**
